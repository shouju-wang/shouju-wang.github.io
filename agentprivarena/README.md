# AgentPrivArena project page

Published at https://shouju-wang.github.io/agentprivarena/ as part of the personal homepage repository. Edit this directory; pushes to `master` publish it automatically.

- `index.html`: narrative, result tables, authors, links, citation, and More Research navigation.
- `static/css/mpci.css`: shared research-page style and title spacing; `arena.css` contains project-specific layouts.
- `static/js/`: figure viewer, citation copying, and navigation.
- `static/data/results.json`: exact Table 4 values from the manuscript.
- `assets/agentprivarena.pdf`: original author-supplied manuscript.
- `assets/figures/manifest.json`: original figure captions, page numbers, crop bounds, and PDF hash.

Code and dataset buttons remain disabled placeholders at the author's request. Replace them with public resource links in `index.html` when available. The website-source footer link refers to this project page, not the benchmark implementation.

The supplied manuscript is an anonymous ACL submission; this page claims no conference acceptance. Author identities are confirmed by the exact-title listing at https://hpzhang94.github.io/research/. The citation year is the PDF's 2026 manuscript-file year. All figures retain original artwork.
